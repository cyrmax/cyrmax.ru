Сегодня мне пришлось практически взламывать свою собственную учётную запись в Windows.

Дело в том, что некоторые крупные обновления винды немножечко так ломают ваш пароль, и даже если вы не доверяли своей памяти и записали пароль на бумажку, это вам не поможет.

Винда начинает считать любой пароль неверным, как будто бы внутри системы что-то сломалось.

Как понимаете, сменить пароль в таком случае штатными средствами не получается.

Опция "забыл пароль" почему-то у меня вообще не отображалась, и мне пришлось искать другие способы решения проблемы.

Благо хоть в саму систему я мог войти без проблем, ибо и пинкод, и отпечаток пальца продолжали работать как ни в чём не бывало.

## В чём засада

В панели управления Windows 11 опции смены пароля больше нет. Вернее, она есть, но только у аккаунта локального администратора, который включать я не советую, ибо риск безопасности.

В новомодных параметрах системы изменить пароль не получится без ввода старого, а его-то винда и не принимает.

Получается прекрасная ситуация:

- пароль вроде бы есть;
- Windows его не принимает;
- PIN работает;
- отпечаток пальца работает;
- сменить пароль через параметры нельзя;
- "забыл пароль" где-то потерялся по дороге.

Люблю современные операционные системы.

## Важное уточнение

Это заклинание имеет смысл, если вы уже вошли в систему и можете открыть консоль с правами администратора.

Это не инструкция по взлому чужих машин и не способ получить доступ в обход защиты.

Ещё один нюанс: `net user` работает с локальными учётными записями Windows. Для аккаунтов Microsoft всё может быть иначе, так что воспринимайте этот текст как описание моего случая, а не как универсальный рецепт на все варианты входа.

## Решение

Единственный и неожиданно простой способ без сторонних подозрительных утилит с левых сайтов - просто ввести одну команду в консоли.

Открываем командную строку с правами администратора.

Для этого нажимаем:

```text
Win + R
````

Пишем:

```text
cmd
```

или:

```text
powershell
```

или:

```text
wt
```

если у вас Windows 11 и установлен Windows Terminal.

Дальше вместо `Enter` нажимаем:

```text
Ctrl + Shift + Enter
```

Если у вас не выключен контроль учётных записей, то вы получите стандартное защищённое окно с подтверждением. Нажимаем в нём "Да" и попадаем в командную строку с правами администратора.

## Сначала можно посмотреть имя пользователя

На всякий случай можно выполнить:

```cmd
net user
```

Команда покажет список пользователей на компьютере.

Чаще всего имя пользователя совпадает с именем папки в:

```text
C:\Users\
```

Например, в моём случае это:

```text
C:\Users\cyrmax
```

Значит имя пользователя - `cyrmax`.

## Смена пароля

Дальше всё ограничивается одной простой командой:

```cmd
net user username password
```

Где:

* `username` - ваше имя пользователя;
* `password` - новый пароль.

Например:

```cmd
net user cyrmax NewStrongPassword123
```

Команда выполняется быстро, без подтверждений и даже ничего не переспрашивает по десять раз.

## Лучше вводить пароль скрыто

Есть более аккуратный вариант:

```cmd
net user username *
```

Например:

```cmd
net user cyrmax *
```

После этого Windows попросит ввести новый пароль в консоли.

Этот вариант лучше тем, что пароль не светится прямо в командной строке и не остаётся видимым на экране.

Полезно, если вам смотрят в монитор, вы записываете экран или просто печётесь о своей цифровой безопасности.

## После смены пароля

Единственное, к чему нужно быть готовым: на следующем входе в систему ничто кроме пароля работать не будет.

Чтобы снова использовать PIN-код, сканер лица или отпечаток пальца, нужно будет один раз войти в Windows с новым паролем.

После этого Windows Hello обычно снова начинает нормально жить.

## В заключение

Пользуйтесь и не попадайте в ситуации, похожие на мою.

А если попали - не бегите сразу качать странные "password recovery ultimate super tool 3000" с сайтов, где одна кнопка "скачать" и пять троянов вокруг.

Иногда вся магия уже лежит в Windows и называется:

```cmd
net user
```
